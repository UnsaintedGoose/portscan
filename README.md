# TCP Port Scanner

Пакет для конкурентного сканирования TCP-портов на Go.

## Возможности
- Поддержка IPv4, IPv6 и DNS-имен.
- Конкурентное сканирование с настраиваемым пулом воркеров.
- Отмена сканирования через `context.Context`.
- Структурированные результаты с детальными состояниями портов.
- Отсутствие внешних зависимостей (только стандартная библиотека).
- Безопасность при конкурентном использовании (проходит `go test -race`).

## Установка
```bash
go get github.com/yourusername/portscan
